* DONE Bài 4 — Theme không load                                     :vừa:bug:
- Chỗ sửa :: [[file:../modules/my-ui.el::7][modules/my-ui.el:7-9]]
- Lý do :: =use-package modus-themes= sẽ =require= feature =modus-themes=.
  Theme có sẵn của Emacs nằm trong =etc/themes/=, không có trong =load-path=,
  nên =require= có thể thất bại và =:config= bị bỏ qua.
- Kiểm tra *trước khi sửa* :: Khởi động Emacs, mở =*Warnings*= và =*Messages*=,
  tìm dòng "Cannot load". Ghi lại bạn thấy gì bên dưới.
- Gợi ý :: =load-theme= không cần =require=. Có thực sự cần =use-package= ở đây không?
- Tìm hiểu :: =C-h v custom-theme-load-path=, =C-h f load-theme=

* DONE Bài 6 — Tree-sitter mở sai mode                                  :khó:
- Chỗ sửa :: [[file:../modules/my-coding.el::16][modules/my-coding.el:16-20]]
- Lý do ::
  - =typescript-mode= không có sẵn trong Emacs → dòng remap không bao giờ khớp.
  - Go, Rust không có mode cũ để remap, nên cần cách khác để Emacs biết mở

  gõ =C-h v major-mode= và điền bảng dưới.
- Gợi ý :: So sánh =auto-mode-alist= với =major-mode-remap-alist=. Hai biến
  giải quyết hai việc khác nhau.

| Đuôi file | Mode mong muốn     | Mode thực tế |
|-----------+--------------------+--------------|
| .go       | go-ts-mode         |              |

| .js       | js-ts-mode         |              |

* Ngoài lề — Eglot cần language server
Eglot chỉ là client, cần có server trong =PATH=:
| Ngôn ngữ   | Server                     | Đã cài? |
|------------+----------------------------+---------|
| Go         | gopls                      |         |
| Rust       | rust-analyzer              |         |
| Ruby       | ruby-lsp / solargraph      |         |
| JS/TS      | typescript-language-server |         |
| Bash       | bash-language-server       |         |

Kiểm tra: =M-: (executable-find "gopls")=. Nếu cài qua mise thì shims trong
=my-env.el= đã lo phần =PATH=.
